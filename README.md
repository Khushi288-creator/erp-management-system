# ERP Management System (MERN Stack)

Full-stack ERP to manage products, customers, suppliers,
sales orders, purchase orders, GRN and invoices.

## Features
- JWT login and register
- Role-based access (Admin, Sales, Purchase, Inventory)
- Passwords hashed with bcrypt

## Tech Stack
React, Node.js, Express, MongoDB, JWT

## Setup
1. cd backend
2. npm install
3. Copy .env.example to .env and fill in values
4. npm run dev
